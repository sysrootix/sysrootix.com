Как один человек тянет отдел

Я — архитектор и отвечаю за прод. Код пишет команда агентов по моей схеме, она открыта на GitHub ↗

  1. Проектирую

    Разбираю задачу с бизнесом. Деньги, бонусы и 1С продумываю до кода: транзакции, порядок, откат.

  2. Режу на шаги

    Старшая модель делит задачу на шаги по 1–5 файлов, каждый проверяется одной командой.

  3. Агенты пишут

    Младшие модели пишут код по ТЗ: сначала тесты, потом реализация до зелёного.

  4. Ревью и CI

    Отдельный агент проверяет diff, хуки не дают сдать красное, CI гоняет тесты.

  5. Выкат

    Merge — и в проде. Упала проверка после выката — автооткат.

одна задача от постановки до прода

  1. $ задача «5LB: бонусы сгорают у неактивных клиентов»
  2. opus план: 3 шага, начисление в одной транзакции, откат продуман
  3. haiku шаг A: тесты написаны, падают как надо
  4. haiku шаг B: реализация, все тесты зелёные
  5. review отдельный агент проверил diff, одно замечание исправлено
  6. ci lint · тесты · сборка ✓
  7. deploy merge → прод, проверка после выката ok
